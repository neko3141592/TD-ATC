# My Project - 高精度鉄道運転シミュレーター

## 概要

このプロジェクトは、Unityで開発されている高精度な鉄道運転シミュレーターです。日本の通勤・通急型電車をモデルとし、リアルな車両物理、複雑な線路配置、そしてATC（自動列車制御装置）やTASC（定位置停止支援装置）といった高度な保安装置の挙動を再現することを目指しています。

単なるゲームではなく、「運転操作が気持ちよく、保安装置の学習にもなる」体験を提供することを目的とした、学習・演習用途にも耐えうるシミュレーターです。

## 主な機能

### 実装済み / 開発中

*   **リアルな車両物理演算:**
    *   `F=ma`に基づいた力行・制動モデル。
    *   勾配抵抗、カーブ抵抗、空気抵抗を考慮した走行。
    *   回生ブレーキと空気ブレーキの連携。
*   **保安装置シミュレーション:**
    *   **ATC (Automatic Train Control):** 信号現示に従ったリアルタイムの速度制限と自動ブレーキ作動。
    *   **TASC (Train Automatic Stopping Controller):** 駅の停止位置に高精度で自動停止するためのパターン生成と追従制御。（開発中）
    *   **定速走行機能:** 設定した速度を自動で維持。
*   **データ駆動型の設計:**
    *   車両の性能（加速度、ブレーキ力など）や線路の情報を外部ファイル（ScriptableObject）から読み込むことで、容易にカスタマイズ可能。
*   **サウンド:**
    *   VVVFインバータ制御をシミュレートしたモーター音。

### 将来的な実装計画

*   **複雑な線路配置:** 複線、待避線、渡り線（ポイント）に対応。
*   **複数車両編成:** 各車両が独立した物理演算を持つ、よりリアルな列車挙動。
*   **AI列車:** 対向列車や並走列車。

## 技術的な特徴

*   **グラフベースの線路モデル:** ノードとエッジで線路を表現し、複雑な分岐や合流にも対応可能な柔軟な構造。
*   **モジュール化されたコンポーネント:** 車両の各機能（動力、ブレーキ、保安装置など）がコンポーネントとして独立しており、再利用性と拡張性が高い設計。
*   **BVE Trainsimの概念を参考:** 線路座標や構文の解析において、定評のあるBVE Trainsimのデータ構造や概念を参考にしています。

## プロジェクト構成

```
Assets/
├── Scripts/
│   ├── Core/         # 列車仕様・編成定義・共通データ
│   ├── Train/        # 走行・制動・力行・VVVF・TASC
│   ├── Safety/       # ATC制御
│   ├── Track/        # 線路グラフ・駅・停止点
│   ├── Audio/        # VVVF音・ブレーキ音
│   └── UI/           # 運転台HUD・メーター表示
│
├── docs/             # 設計資料・ロードマップ
└── ...               # モデル、サウンドなどのアセット
```

## 開発ロードマップ

開発は以下のフェーズで進行しています。

1.  **基礎走行:** 加速・減速・惰行の基本物理モデルの実装。
2.  **データ駆動化:** 車両・線路パラメータの外部化。
3.  **ATC基礎:** 信号現示に基づく速度制限。
4.  **定速運転:** 指定速度の自動維持。
5.  **TASC:** 駅への自動停止機能の実装。
6.  **線路拡張:** 複線・分岐への対応。
7.  **対話的環境:** AI列車の追加。

詳細なドキュメントは `docs/` ディレクトリを参照してください。
