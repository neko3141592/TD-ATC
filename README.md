# 鉄道運転シミュレータ プロジェクト

## プロジェクト概要

本プロジェクトは、Unityを用いて鉄道車両の物理挙動、保安装置、および走行音などを正確にシミュレーションする鉄道運転ゲーム開発プロジェクトです。車両ごとの性能差を表現するデータ駆動型の設計を採用し、力行から制動までの滑らかな操作感に加え、ATCやTASCといった高度な自動制御システムの再現を目的としています。

## システムアーキテクチャ・主要機能

本シミュレータの実装は、以下の主要なモジュールによって構成されています。

### 1. 車両・走行物理モデル
列車の走行挙動と編成全体の物理シミュレーションを管理します。単一の車両だけでなく、複数車両の連結（編成）を想定したモデルとなっています。
- **走行制御**: マスコン入力から加減速計算までの統合的な制御を行います。ノッチ（力行・制動段数）の管理に応じた正確な挙動を再現します。
- **ブレーキシステム**: 空気ブレーキと回生ブレーキを融合したシステムを構築し、リアルな制動モデルを実装しています。
- **性能データの分離**: 車両ごとに異なる性能（加速度、減速度、走行抵抗など）は外部データとして定義され、柔軟にパラメータ調整ができる設計です。
- **環境抵抗**: 現在の勾配やカーブなどの環境要素が計算され、列車の加速度に動的に反映されます。

### 2. 軌道・線路システム
走行のベースとなる線路網は、拡張性の高いグラフ構造として表現・管理されています。
- **グラフネットワーク**: 線路の接続や分岐が表現されます。列車の進行方向によるルート検索や、分岐器の切り替えもシミュレートします。
- **閉塞管理**: 各線路区間（閉塞区間）への列車の在線を管理し、保安装置に正確な信号情報を提供します。
- **コース生成**: 設定された道筋に沿って3Dの線路モデルを生成します。

### 3. 保安装置・自動制御システム
安全な運行や、正確な駅への停止を実現するための制御系モデルです。
- **ATC（自動列車制御装置）**: 前方を走行する列車の位置や制限速度の境界に基づき、許容速度パターンを計算し、超過時の自動減速処理を行います。
- **TASC（定位置停止支援装置）**: 駅到着時の制動を自動化し、目標となる停止位置までの残距離を基に、正確な停車を支援します。

### 4. ユーザーインターフェース (UI)
実際の運転台を模した各種メーターやインジケータを画面上に描画します。
- **メーター描画**: 現在の速度やブレーキ圧力を表示します。
- **状態表示**: マスコンの状態から、ATCの現示速度、TASCの作動状況などを運転士に視覚的にフィードバックします。

### 5. サウンドおよびインバータ制御
高品質な聴覚的フィードバックを提供します。
- **VVVFサウンド合成**: 単なる音声ファイルの再生ではなく、インバータの制御周波数を計算し、速度に応じたリアルタイムの走行音生成を構築しています。
- **環境音・機器音**: 車内ブザーやコンプレッサの動作音なども組み込まれ、臨場感を高めています。
