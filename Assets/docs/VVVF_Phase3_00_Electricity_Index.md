# VVVF フェーズ 3: 電気と電磁気の基礎 目次

## このフェーズの目的

Phase 3 では、VVVF を理解するために必要な電気と電磁気の入口を学びます。

ここでの目標は、電気工学を完全にマスターすることではありません。まずは、次の言葉をシミュレーターの値として理解できるようにします。

```text
電圧 V
電流 A
抵抗 ohm
電力 W
直流 DC
交流 AC
周波数 Hz
実効値 RMS
位相
力率
磁界
コイル
電磁誘導
三相交流
```

Phase 0 から Phase 2 までで、速度、rpm、波、トルク、出力を扱いました。Phase 3 では、機械側の `W` と電気側の `W` をつなげます。

```text
機械側:
powerW = forceN * speedMS
powerW = torqueNm * angularSpeedRadS

電気側:
powerW = voltageV * currentA
```

## Phase 3 の到達目標

Phase 3 が終わったら、次のことを説明できる状態を目指します。

- 電圧は「1 C あたりのエネルギー」だと説明できる
- 電流は「1 秒あたりに流れる電荷量」だと説明できる
- `V * A = W` の単位変換が分かる
- 直流と交流の違いを説明できる
- 交流では電圧や電流がプラスとマイナスに変化すると分かる
- 実効値が「同じ発熱をする直流に換算した値」だと分かる
- コイルでは電流が急に変わりにくいと分かる
- 電流が流れると磁界ができると分かる
- 三相交流で回転磁界を作れる理由の入口が分かる
- VVVF では周波数、電圧、電流が別々の役割を持つと分かる

## VVVF でのざっくり対応

先に全体像だけ置いておきます。

```text
周波数 frequencyHz
  -> 回転磁界の速さを決める
  -> モーターの回転数に関係

電圧 voltageV
  -> 電流を流そうとする強さ
  -> モーターの磁束や出せるトルクに関係

電流 currentA
  -> 実際に流れている量
  -> トルク、発熱、電流計に関係
```

かなり単純化すると、

```text
周波数 = どれくらい速く回したいか
電圧 = どれくらい強く押すか
電流 = 実際にどれくらい仕事しているか
```

です。

ただしモーターはただの抵抗ではありません。コイル、磁界、回転、すべり、制御が関係するので、電圧と電流は単純な比例だけでは決まりません。

## 読む順番

おすすめはこの順番です。

```text
01 電荷・電圧・電流
  -> 02 直流・抵抗・電力
  -> 03 交流・実効値・位相
  -> 04 磁界・コイル・電磁誘導
  -> 05 VVVF と電流
```

途中で分からなくなったら、Phase 1 の sin 波と Phase 2 の出力 `W` に戻るとつながりやすいです。
