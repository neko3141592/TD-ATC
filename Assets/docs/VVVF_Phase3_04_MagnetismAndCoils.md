# VVVF フェーズ 3-4: 磁界・コイル・電磁誘導

## この章のゴール

この章では、電磁気をまったく知らない状態から、モーター理解に必要な入口までを扱います。

VVVF とモーターでは、電気だけでは足りません。電流が磁界を作り、磁界が力を作り、モーターが回ります。

まずはこの流れを理解します。

```text
電流が流れる
  -> 磁界ができる
  -> コイルが電磁石になる
  -> 磁界同士が力を出す
  -> モーターが回る
```

## 1. 磁界とは何か

磁界は、磁石の力が働く空間です。

普通の磁石には、

```text
N極
S極
```

があります。

磁石同士を近づけると、

```text
N と S は引き合う
N と N は反発する
S と S は反発する
```

という力が出ます。

この磁石の力が働く空間を、磁界と考えます。

## 2. 電流は磁界を作る

電流が流れると、その周りに磁界ができます。

これはモーターの基本です。

```text
電流
  -> 磁界
```

電流の向きを逆にすると、磁界の向きも逆になります。

```text
電流が正向き
  -> 磁界の向き A

電流が逆向き
  -> 磁界の向き B
```

つまり、電流の向きを変えれば、磁界の向きも変えられます。

## 3. コイルとは何か

コイルは、導線をぐるぐる巻いたものです。

導線 1 本に電流を流しても磁界はできますが、巻くことで磁界を強くできます。

```text
導線を巻く
  -> 磁界が重なる
  -> 強い磁界になる
```

コイルに電流を流すと、コイルは磁石のようになります。

これを電磁石と考えられます。

```text
コイル + 電流 = 電磁石
```

## 4. 電流の向きで N/S が変わる

コイルに流れる電流の向きを逆にすると、電磁石の N 極と S 極も逆になります。

```text
電流が正向き
  -> 左が N、右が S

電流が逆向き
  -> 左が S、右が N
```

これは交流モーターで重要です。

交流では電流の向きが周期的に変わるので、コイルの磁界の向きも周期的に変わります。

## 5. 単相交流だけだと何が起きるか

1 本の交流を 1 つのコイルに流すと、磁界の強さと向きが変化します。

```text
正向きに強い
  -> 0
  -> 逆向きに強い
  -> 0
  -> 正向きに強い
```

これは、同じ方向で行ったり来たりする磁界です。

```text
単相交流:
磁界が振動する感じ
```

モーターをなめらかに回すには、振動する磁界よりも回転する磁界が必要です。

## 6. 三相交流で回転磁界を作る

三相交流では、3 つのコイルに 120 度ずつずれた電流を流します。

```text
U相
V相
W相
```

各相の電流はこうです。

```text
u = sin(angle)
v = sin(angle - 2*pi/3)
w = sin(angle + 2*pi/3)
```

すると、

```text
U相の磁界が強い
  -> V相の磁界が強い
  -> W相の磁界が強い
  -> またU相の磁界が強い
```

という順番になります。

これによって、全体として磁界が回っているようになります。

```text
三相交流
  -> 回転磁界
```

## 7. 回転磁界がモーターを回す

モーターの固定子に三相交流を流すと、固定子の中に回転磁界ができます。

```text
固定子 = 外側の動かない部分
回転子 = 内側の回る部分
```

回転磁界ができると、回転子がその磁界に引っ張られたり、電磁誘導で力を受けたりして回ります。

```text
三相交流
  -> 回転磁界
  -> 回転子に力
  -> モーターが回る
```

これが交流モーターの基本です。

## 8. 電磁誘導とは何か

電磁誘導は、磁界の変化によって電圧が発生する現象です。

かなり単純化すると、

```text
コイルの近くの磁界が変化する
  -> コイルに電圧が発生する
```

です。

発電機はこの仕組みを使います。

```text
磁界の中でコイルを動かす
  -> 磁界が変化する
  -> 電圧が発生する
  -> 電流を取り出せる
```

回生ブレーキでも、モーターを発電機として使います。

## 9. 誘導電動機での電磁誘導

誘導電動機では、固定子の三相交流が回転磁界を作ります。

その回転磁界が回転子に電流を誘導します。

```text
固定子の三相交流
  -> 回転磁界
  -> 回転子に誘導電流
  -> 回転子にも磁界
  -> 固定子の磁界と作用
  -> トルク
```

誘導電動機という名前は、回転子に電流が「誘導」されるところから来ています。

## 10. すべりが必要な理由

誘導電動機では、回転磁界と回転子の間に速度差が必要です。

この速度差をすべりと呼びます。

```text
slip = (synchronousRpm - rotorRpm) / synchronousRpm
```

今は式を完全に覚えなくて大丈夫です。

大事なのは、

```text
回転磁界と回転子の速度差がある
  -> 回転子に誘導が起きる
  -> トルクが出る
```

ということです。

逆に完全に同じ速度で回っていると、誘導が弱くなり、トルクが出しにくくなります。

## 11. 回生ブレーキと電磁誘導

回生ブレーキでは、車輪がモーターを回します。

```text
列車の運動
  -> 車輪
  -> モーター
```

このときモーターを発電機として使い、電気を戻します。

```text
機械エネルギー
  -> 電気エネルギー
```

VVVF は、モーターの電流と周波数を制御して、モーターが負のトルクを出すようにします。

```text
負のトルク
  -> 列車を減速
  -> 電気を直流側へ戻す
```

## 12. PMSM では何が違うか

PMSM は永久磁石同期電動機です。

回転子に永久磁石があります。

```text
誘導電動機:
回転子に誘導電流が生まれる
すべりがある

PMSM:
回転子に永久磁石がある
基本的に回転磁界と同期して回る
```

PMSM は効率が高いですが、回転子の位置を見ながら制御する必要があり、本格実装は難しくなります。

そのため、最初のシミュレーターでは誘導電動機から始めるのが現実的です。

## 13. Unity で磁界そのものを厳密計算する必要はあるか

最初は必要ありません。

VVVF シミュレーターでは、まず次のような状態量で十分です。

```text
frequencyHz
synchronousRpm
motorRpm
slip
voltageV
currentA
torqueNm
```

磁界を厳密に 3D 計算するのではなく、

```text
周波数 -> 同期速度
すべり -> トルク
電流 -> トルクと発熱
```

のように簡略化します。

## 14. モーターの入口モデル

最初の簡易モデルでは、すべりからトルクを作れます。

```text
torque = maxTorque * slip / (slip + slipShape)
```

これは実機の厳密な式ではありません。

しかし、

```text
すべりがあるとトルクが出る
すべりが小さすぎるとトルクが弱い
上限トルクを超えない
```

という性質を実装で確認できます。
