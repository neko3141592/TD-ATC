# VVVF フェーズ 3-1: 電荷・電圧・電流

## この章のゴール

この章では、電気の一番基本になる `電荷`、`電圧`、`電流` を理解します。

VVVF では、インバータやモーターの前に、まず次の関係が必要です。

```text
電圧 V = 電気を動かすためのエネルギー差
電流 A = 実際に流れている電気の量
電力 W = 1 秒あたりに渡されるエネルギー
```

この章の最重要ポイントはこれです。

```text
1 A = 1 C/s
1 V = 1 J/C
V * A = W
```

## 1. 電荷とは何か

電気には、電荷という量があります。単位は `C`、クーロンです。

今は細かい原子の話まで入らなくて大丈夫です。まずは、

```text
電荷 = 電気の量
```

だと思ってください。

水でたとえるなら、

```text
水の量
```

に近いです。

電気では、電子が動くことで電流が流れます。ただし回路図や電気工学では、電流の向きは「プラスからマイナスへ流れる向き」として扱います。

実際の電子の動きとは向きが逆ですが、最初は気にしすぎなくて大丈夫です。

## 2. 電流とは何か

電流は、電荷がどれくらいの勢いで流れているかです。

単位は `A`、アンペアです。

```text
1 A = 1 C/s
```

これは、

```text
1 秒間に 1 C の電荷が流れる
```

という意味です。

例えば、

```text
2 A = 1 秒間に 2 C 流れる
10 A = 1 秒間に 10 C 流れる
```

です。

つまり電流は、

```text
どれだけの電気量が、毎秒流れているか
```

です。

## 3. 電圧とは何か

電圧は、電荷 1 C あたりにどれだけエネルギーを持たせられるかです。

単位は `V`、ボルトです。

```text
1 V = 1 J/C
```

これは、

```text
1 C の電荷を動かすのに 1 J のエネルギー差がある
```

という意味です。

かなり単純化すると、

```text
電圧 = 電気を押す強さ
```

です。

ただし本当は「力」そのものではなく、`1 C あたりのエネルギー差` です。

## 4. 水のたとえ

電気はよく水でたとえます。

```text
電圧 -> 水圧
電流 -> 水の流量
抵抗 -> 管の細さ
```

水圧が高いほど、水は流れやすいです。

管が太いほど、水はたくさん流れます。

電気も似ています。

```text
電圧が高い -> 電流を流しやすい
抵抗が小さい -> 電流が流れやすい
```

ただし、モーターはただの管ではありません。コイルや磁界が関係するので、水のたとえだけでは後で足りなくなります。

## 5. 電力とは何か

電力は、1 秒あたりに使う、または渡すエネルギーです。

単位は `W`、ワットです。

```text
1 W = 1 J/s
```

つまり、

```text
1 秒あたり 1 J のエネルギー
```

です。

Phase 2 では機械側の出力を扱いました。

```text
powerW = forceN * speedMS
powerW = torqueNm * angularSpeedRadS
```

電気側でも、同じ `W` を使います。

```text
powerW = voltageV * currentA
```

## 6. なぜ V * A = W になるのか

ここが重要です。

電圧:

```text
1 V = 1 J/C
```

電流:

```text
1 A = 1 C/s
```

掛けると、

```text
V * A = (J/C) * (C/s)
```

`C` が消えます。

```text
(J/C) * (C/s) = J/s
```

`J/s` は `W` です。

```text
V * A = W
```

つまり、

```text
電圧 = 1 C あたりのエネルギー
電流 = 1 秒あたりに流れる C
```

なので、掛けると、

```text
1 秒あたりに渡されるエネルギー
```

になります。

## 例 1: 電圧と電流から電力

```text
voltageV = 100
currentA = 2
```

```text
powerW = voltageV * currentA
powerW = 100 * 2
powerW = 200
```

答え:

```text
200 W
```

単位で見ると、

```text
100 J/C * 2 C/s = 200 J/s
```

です。

## 例 2: 電車の電力

架線電圧が `1500 V`、電流が `1000 A` のとき、

```text
powerW = 1500 * 1000
powerW = 1500000
```

答え:

```text
1.5 MW
```

`MW` はメガワットです。

```text
1 MW = 1000000 W
```

## 7. 電圧が高いと何がうれしいか

同じ電力を送る場合、

```text
powerW = voltageV * currentA
```

なので、電圧が高いほど必要な電流を小さくできます。

例:

```text
必要電力 = 3000000 W
```

1500 V の場合:

```text
currentA = 3000000 / 1500
currentA = 2000 A
```

750 V の場合:

```text
currentA = 3000000 / 750
currentA = 4000 A
```

同じ 3 MW でも、電圧が半分だと電流は 2 倍必要です。

電流が大きいと、

```text
ケーブルが太く必要
発熱が増える
損失が増える
装置が大きくなる
```

ので、大電力では高い電圧が有利です。

## 8. 電流が大きいと何が起きるか

電流が大きいと、モーターで大きなトルクを出しやすくなります。

ただし同時に、

```text
発熱が増える
半導体や配線に負担がかかる
電流制限に当たりやすい
空転しやすくなる
```

という問題があります。

VVVF では、電流を好きなだけ流すのではなく、電流上限を守りながらモーターを制御します。

## 9. 電圧・電流・周波数の役割

VVVF では、電圧、電流、周波数が全部出てきます。

最初はこう分けて考えると分かりやすいです。

```text
周波数 frequencyHz
  -> 波の速さ
  -> 回転磁界の速さ
  -> モーター回転数に関係

電圧 voltageV
  -> 電流を流そうとする強さ
  -> 磁束やトルクに関係

電流 currentA
  -> 実際に流れている量
  -> トルク、発熱、電流計に関係
```

電車の運転で見える電流計は、

```text
今どれくらい電気的に頑張っているか
```

を表す値だと考えると分かりやすいです。

## 10. Unity での値の持ち方

コードでは、変数名に単位を入れます。

```csharp
float voltageV = 1500f;
float currentA = 1000f;
float powerW = voltageV * currentA;
```

表示用には、`kW` や `MW` に変換すると見やすいです。

```csharp
float powerKW = powerW / 1000f;
float powerMW = powerW / 1000000f;
```

## 練習問題

### 問題 1

`1 A` は何 `C/s` ですか。

答え:

```text
1 C/s
```

### 問題 2

`1 V` は何 `J/C` ですか。

答え:

```text
1 J/C
```

### 問題 3

`1500 V`、`800 A` のとき、電力は何 `MW` ですか。

解き方:

```text
powerW = 1500 * 800
powerW = 1200000
```

答え:

```text
1.2 MW
```

## チェックリスト

- 電荷 `C` は電気の量だと分かる
- 電流 `A` は `C/s` だと分かる
- 電圧 `V` は `J/C` だと分かる
- `V * A = W` を単位で説明できる
- 電車では大電力を扱うので電流が大きくなると分かる
